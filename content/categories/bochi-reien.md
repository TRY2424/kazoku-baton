## お墓のかたちは、大きく6つ

いまはお墓のかたちもさまざまです。

| かたち | ひとことで |
|---|---|
| 一般墓 | 家族で代々受け継ぐ、墓石のあるお墓 |
| 永代供養墓 | お寺や霊園が、家族に代わって供養・管理してくれるお墓 |
| 納骨堂 | 屋内の施設に遺骨を納めるお墓 |
| 樹木葬 | 墓石の代わりに、木や草花を墓標にするお墓 |
| 海洋散骨 | 粉にした遺骨を海にまく供養 |
| 手元供養 | 遺骨の一部を自宅などで保管する供養 |

それぞれの特徴と費用の目安は、[お墓の種類と選び方｜はじめての方のための全体ガイド](/blog/bochi-reien-guide) で早見表にしています。

## 3つの問いで考える

1. **お墓を継いでくれる人はいる？**
   いる → 一般墓や納骨堂も選択肢に。いない・負担をかけたくない → 永代供養墓・樹木葬・海洋散骨
2. **手を合わせに行ける「場所」を残したい？**
   残したい → 一般墓・納骨堂・樹木葬。こだわらない → 海洋散骨（手元供養と組み合わせることも）
3. **費用はどのくらいまで？**
   おさえたい → 合祀型の永代供養墓や樹木葬。家族の区画がほしい → 一般墓や個別型の樹木葬

「自然に還る」供養で迷ったら、[樹木葬と海洋散骨、どちらを選ぶ？](/blog/jumokusou-kaiyousankotsu) で比べています。

## 実家のお墓をどうする？（墓じまい）

遠くにある実家のお墓を守り続けるのが難しくなったとき、墓じまいという選択肢があります。お寺や霊園への相談、役所での手続き（改葬許可）、墓石の撤去などが必要です。

- [墓じまいして海へ還す｜実家のお墓を海洋散骨にする流れと費用](/blog/hakajimai-sankotsu)
- [大阪湾で海洋散骨｜費用・流れ・当日のようす](/blog/osaka-kaiyousankotsu)

## 親の希望を聞いておく

お墓や供養のことは、親が元気なうちに希望を聞いておくと、あとで家族が迷わずにすみます。財産や介護のことと一緒に考えるなら、[生前整理](/categories/seizen-seiri)のジャンルも参考にしてください。

> ※ 費用や手続きは、お寺・霊園・自治体によって違います。契約の前に、必ず内容を確かめてください。
