実家に帰ったら、見たことのない布団や健康器具がある。貴金属を安く買い取られたらしい。親の消費者トラブルに気づいたとき、まず確認したいのが**クーリング・オフ**です。

この記事は、消費者庁「特定商取引法ガイド」をもとに書いています（出典は記事の最後に載せています）。

> ※ 個別の契約でできるかどうかは事情によります。迷ったら、すぐに**消費者ホットライン 188**に相談してください。最寄りの消費生活相談窓口を案内してもらえます。

## クーリング・オフできる期間

| 取引 | 期間 |
|---|---|
| **訪問販売**（キャッチセールス、アポイントメントセールスを含む） | **8日以内** |
| **訪問購入**（訪問買取） | **8日以内** |
| 電話勧誘販売 | 8日以内 |
| 特定継続的役務提供 | 8日以内 |
| 連鎖販売取引、業務提供誘引販売取引 | 20日以内 |
| **通信販売** | **クーリング・オフの規定はない** |

期間は、**法定の書面を受け取った日**から数えます。手続きは、書面または電磁的記録で行います。

**事業者が事実とちがうことを言ったり、おどしたりして**クーリング・オフできなかった場合は、期間を過ぎてもできます。

## 訪問販売のクーリング・オフ

- 自宅など、営業所以外の場所で契約した場合が対象
- 消耗品を使ってしまった場合や、現金取引で代金の総額が3,000円未満の場合は、できないことがあります

**量が多すぎる契約**にも対応があります。通常必要な量を著しくこえる契約は、契約から**1年間**は申込みの撤回や解除ができます（その契約を結ぶ特別の事情があった場合を除く）。何枚もの布団などに気づいたら、相談してみましょう。

## 訪問購入（訪問買取・押し買い）のルール

自宅に来て貴金属などを買い取る取引です。

| ルール | 内容 |
|---|---|
| **頼んでいない勧誘は禁止** | 勧誘を頼んでいない人の自宅で、勧誘したり意思を確認したりしてはいけない |
| 査定だけのはずが… | 査定を頼まれた場合も、査定をこえて勧誘することは認められない |
| **断ったら再勧誘は禁止** | 契約の意思がないと示した人に、続けて勧誘してはいけない |
| **書面** | 物品の種類、購入価格、事業者の情報、解除に関することなどを書いた書面を渡す |
| **渡さなくていい** | クーリング・オフ期間中は、**品物の引き渡しを拒める**。事業者はそのことを伝えなければならない |
| 第三者に渡したとき | 事業者は、渡した先などを遅滞なく通知しなければならない |

政令で定める物品は対象外です。実家の[車を売るときのトラブル](/blog/oya-kuruma-baikyaku-trouble)は別の記事にまとめています。

## 家族ができること

この記事としてのおすすめです。

1. **日付を確認する**：契約書や書面を探し、受け取った日を確認する
2. **すぐ188に電話する**：8日は短いので、迷う時間をなくす
3. **親を責めない**：責められると隠すようになり、次に気づきにくくなります
4. **判断能力が心配なら**：[日常生活自立支援事業](/blog/nichijo-seikatsu-jiritsu-shien)や[成年後見](/blog/seinen-kouken-moushitate)、[地域包括支援センター](/blog/chiiki-houkatsu-shien-center)にも相談する

## まとめ

- 訪問販売、訪問買取は、**書面を受け取った日から8日以内**ならクーリング・オフできる
- うそやおどしでできなかったときは、期間を過ぎてもできる
- 量が多すぎる訪問販売は、**1年間**解除できる
- 訪問買取は、期間中は品物を渡さなくていい
- 困ったら**188**
