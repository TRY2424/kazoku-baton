親が75歳をこえて、過去に交通違反をしていると、免許の更新のときに**運転技能検査**を受けることがあります。どんな人が対象で、何をして、何点で合格なのかを、警察庁の公式ページなどをもとにまとめました（出典は記事の最後に載せています）。

## 対象になる人

**75歳以上**で、一定の**違反歴**がある人です。違反歴は、更新の基準日（免許が切れる前の最後の誕生日の160日前など）の前の**3年間**で見ます。合格しないと、免許を更新できません。

### 対象になる違反（11類型）

| | |
|---|---|
| 信号無視 | 通行区分違反 |
| 通行帯違反等 | 速度超過 |
| 横断等禁止違反 | 踏切不停止等・遮断踏切立入り |
| 交差点右左折方法違反等 | 交差点安全進行義務違反等 |
| 横断歩行者等妨害等 | 安全運転義務違反 |
| 携帯電話使用等 | |

## 何をする？何点で合格？

| 項目 | 内容 |
|---|---|
| 検査 | 試験場や教習所のコースで普通自動車を運転し、**一時停止**などの課題をこなす |
| 採点 | 運転の危なさに応じて、**100点から減点** |
| 合格 | 第一種免許は**70点以上**、第二種免許は**80点以上** |

大阪府警察の案内では、課題は指示速度での走行、一時停止、交差点の右左折、信号の通過、段差の乗り上げです。

## 不合格だったら

<div class="steps">

1. 不合格だと、その時点では更新できない
2. 警察庁のリーフレットでは、**受け直すことができる**とされている。受けるたびに手数料がかかる（奈良県警察の案内）
3. 更新の期限までに合格できるよう、**早めに1回目を受けておく**
4. 合格したら、高齢者講習（1時間）を受けて更新する

</div>

受け直す時間を残すためにも、通知が届いたらすぐに予約しましょう。会場の空き状況は[大阪](/blog/koureisha-koushuu-yoyaku)・[兵庫](/blog/koureisha-koushuu-hyogo)・[京都](/blog/kyoto-koureisha-koushuu)・[奈良](/blog/nara-koureisha-koushuu)にまとめています。

## 手数料（関西の例）

| 府県 | 運転技能検査の手数料 |
|---|---|
| 大阪府 | 3,650円（標準額） |
| 奈良県 | 3,650円 |

奈良県警察によると、奈良県の運転技能検査は運転免許センター（橿原市）だけで受けられます。

## 見直しの動き

警察庁は2026年9月、運転技能検査の見直しに関する有識者検討会の報告書を公表しました。報告では、合格したあとに事故を起こした人に「一時停止」の減点が多かったことなどから、減点の基準の見直しについての意見がまとめられています。制度が変わるかどうかは、今後の発表を確かめてください。

## まとめ

- 対象は、75歳以上で更新前3年間に11類型の違反をした人
- コースで一時停止などの課題をこなし、100点からの減点で70点以上なら合格（第一種）
- 不合格でも受け直せる。期限に間に合うよう早めに受ける
- 合格しないと更新できないので、免許の返納も含めて家族で話し合うきっかけに
