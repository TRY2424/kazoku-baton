これまでの記事で「要介護3以上」「要支援2以上」といった言葉が何度か出てきました。この「要介護」「要支援」という仕組みを理解しておくと、施設選びの全体像がぐっと分かりやすくなります。

## 要介護認定とは何か

要介護認定とは、**その方がどのくらい介護や支援を必要としているかを、国の基準に基づいて判定する仕組み**です。市区町村の窓口に申請すると、調査員による訪問調査や主治医の意見書などをもとに、以下のいずれかに区分されます。

- **非該当**:介護や支援が必要ないと判定された状態
- **要支援1・2**:日常生活に一部支援が必要な状態(比較的軽度)
- **要介護1〜5**:日常生活に介護が必要な状態(数字が大きいほど介護の必要度が高い)

この区分によって、利用できるサービスの種類や、施設に入居できるかどうかが変わってきます。

## 要支援と要介護、何が違う?

簡単に言うと、**要支援は「予防」の段階、要介護は「介護」が必要な段階**というイメージです。

- 要支援1・2:主に「介護予防サービス」を利用しながら、状態の維持・改善を目指す
- 要介護1〜5:主に「介護サービス」を利用しながら、日常生活のサポートを受ける

例えば、以前の記事で紹介した「グループホーム」は要支援2以上が対象、「特別養護老人ホーム(特養)」は原則要介護3以上が対象、というように、施設ごとに対象となる区分が決まっています。

## 施設選びにどう影響するか

要介護度によって、選べる施設の選択肢は次のように変わってきます。

| 要介護度 | 選択肢の例 |
|---|---|
| 非該当・要支援1〜2 | サ高住、住宅型有料老人ホーム、グループホーム(要支援2以上) |
| 要介護1〜2 | 介護老人保健施設(老健)、介護付き有料老人ホーム |
| 要介護3以上 | 特別養護老人ホーム(特養)、介護付き有料老人ホーム |

つまり、「今の要介護度で、そもそも入居できる施設はどこか」を最初に確認しておくことで、無駄な施設見学や問い合わせを減らすことができます。

## 要介護度は何で決まる？（基準時間の一覧）

厚生労働省によると、要介護度は、病気の重さではなく<mark>介護サービスがどれくらい必要か（介護の手間）</mark>で判定されます。そのため、病気が重くても要介護度が低く出ることや、認知症で介護の手間が大きいと要介護度が高く出ることがあります。

コンピュータによる一次判定では、認定調査の結果から「**要介護認定等基準時間**」を推計し、次の区分にあてはめます。

| 区分 | 要介護認定等基準時間 |
|---|---|
| 要支援1 | 25分以上32分未満 |
| 要支援2・要介護1 | 32分以上50分未満 |
| 要介護2 | 50分以上70分未満 |
| 要介護3 | 70分以上90分未満 |
| 要介護4 | 90分以上110分未満 |
| 要介護5 | 110分以上 |

（厚生労働省「要介護認定はどのように行われるか」、要介護認定等に係る介護認定審査会による審査及び判定の基準等に関する省令）

> **注意**：この時間は、介護の必要性をはかる「ものさし」です。厚生労働省は、**家庭で実際に行われている介護の時間とは違う**と説明しています。「1日に50分しか介護しなくていい」という意味ではありません。

### 要支援2と要介護1の分かれ目

基準時間が32分以上50分未満の人は、「要支援2」か「要介護1」のどちらかになります。厚生労働省の説明では、次のような場合は**要介護1**になります。

- 病気やけがで心身の状態が安定しておらず、短い期間で状態を見直す必要がある
- 認知症などで、介護予防のサービスを利用することを十分に理解するのが難しい

どちらにも当てはまらなければ要支援2です。最終的には、保健・医療・福祉の専門家による二次判定（介護認定審査会）で決まります。

## 1か月に介護保険で使える額（支給限度額）

在宅で介護保険のサービスを使うとき、要介護度ごとに、1か月に使える上限（区分支給限度基準額）が決まっています。

| 区分 | 1か月の支給限度額 | 1単位10円で計算した目安 |
|---|---|---|
| 要支援1 | 5,032単位 | 約5万円 |
| 要支援2 | 10,531単位 | 約10.5万円 |
| 要介護1 | 16,765単位 | 約16.8万円 |
| 要介護2 | 19,705単位 | 約19.7万円 |
| 要介護3 | 27,048単位 | 約27万円 |
| 要介護4 | 30,938単位 | 約30.9万円 |
| 要介護5 | 36,217単位 | 約36.2万円 |

（世田谷区の案内より。全国共通の額です）

- **自己負担**：限度額の中で使った分の1割〜3割です（[負担割合は1割？2割？3割？](/blog/kaigo-hoken-futan-wariai)）。1割負担で要介護1の限度額いっぱいまで使うと、月に約1万7千円が目安です
- **限度額をこえた分**：全額が自己負担になります
- **1単位の値段**：地域やサービスの種類によって10円より高くなることがあるので、金額はあくまで目安です

施設に入った場合は、この限度額ではなく、施設ごとの決まった料金になります。施設の費用は[老人ホームの費用](/blog/roujin-home-hiyou)にまとめています。自己負担が高くなった月は[高額介護サービス費](/blog/kougaku-kaigo-service-hi)で戻る分があります。

## 要介護認定を受けるための流れ

1. お住まいの市区町村の窓口に申請（地域包括支援センターに相談することもできます）
2. 認定調査員による訪問調査(心身の状態についての聞き取り)
3. 主治医の意見書の提出
4. コンピューターによる一次判定 → 専門家による二次判定
5. 結果の通知（申請から原則30日以内）

申請から結果が出るまで1ヶ月ほどかかることが多いため、**施設探しを本格的に始める前に、早めに申請しておく**ことをおすすめします。

## まとめ

- 要介護認定は、介護の必要度を国の基準で判定する仕組み
- 「要支援(予防段階)」と「要介護(介護が必要な段階)」で、利用できる施設・サービスが異なる
- 施設によって対象となる要介護度が決まっているため、早めに認定を受けておくと施設選びがスムーズになる

次回からは、これまで紹介した施設の中から、特に「特別養護老人ホーム(特養)」に絞って、入居条件や待機期間の実態をさらに詳しく見ていきます。
