親が亡くなったあと、親名義の預金を受け取るには、**銀行での相続手続き**が必要です。必要な書類は、**遺言書や遺産分割協議書があるかどうか**で変わります。

一般社団法人 全国銀行協会（全銀協）の案内をもとに整理しました（出典は記事の最後に載せています）。

> ※ 書類は銀行によってちがうことがあります。実際の手続きは、それぞれの銀行の案内に従ってください。投資信託など、預金以外の手続きは別になります。

## 手続きの流れ

| ステップ | 内容 |
|---|---|
| ① 銀行に連絡 | 口座がある銀行に、亡くなったことを伝える。手続きの案内を受ける |
| ② 口座の取引が止まる | 連絡と同時に、入出金などの取引は**原則として制限**される |
| ③ 書類をそろえる | 遺言書の有無などで必要な書類が変わる（下の表） |
| ④ 書類を出す | 銀行所定の相続手続きの書類に記入し、相続人が署名・捺印して、そろえた書類とあわせて出す |
| ⑤ 払い戻しなど | 銀行で手続きが行われる。**日数がかかる場合がある** |

### 連絡する前に確認しておきたいこと

口座が止まると、公共料金やクレジットカードの引き落としもできなくなります。引き落としの先は、支払い方法の変更や解約の手続きが必要です。葬儀費用など急ぎのお金が必要な場合は、あとで紹介する「払戻し制度」も検討しましょう。

## ケース別の必要書類

### 1. 遺言書がある場合

| 書類 |
|---|
| 遺言書 |
| 検認調書または検認済証明書（**公正証書遺言以外**の場合） |
| 亡くなった人の戸籍謄本または全部事項証明（死亡が確認できるもの） |
| 預金を相続する人の印鑑証明書（遺言執行者がいる場合は遺言執行者の印鑑証明書） |
| 遺言執行者の選任審判書謄本（家庭裁判所で遺言執行者が選ばれている場合） |

自筆の遺言書は、法務局に預けていた場合を除いて、家庭裁判所の検認が必要です（[遺言書の検認](/blog/igonsho-kennin)）。

### 2. 遺言書がなく、遺産分割協議書がある場合

| 書類 |
|---|
| 遺産分割協議書（法定相続人全員の署名・捺印があるもの） |
| 亡くなった人の除籍謄本、戸籍謄本または全部事項証明書（**出生から死亡までの連続したもの**） |
| 相続人全員の戸籍謄本または全部事項証明書 |
| 相続人全員の印鑑証明書 |

遺産分割協議書の作り方は[遺産分割協議書の書き方](/blog/isan-bunkatsu-kyougisho)をご覧ください。全銀協によると、銀行は相続人全員の印鑑証明書で、協議書の署名・捺印を照合します。

### 3. 遺言書も遺産分割協議書もない場合

| 書類 |
|---|
| 亡くなった人の除籍謄本、戸籍謄本または全部事項証明書（出生から死亡までの連続したもの） |
| 相続人全員の戸籍謄本または全部事項証明書 |
| 相続人全員の印鑑証明書 |

### 4. 家庭裁判所の調停調書・審判書がある場合

| 書類 |
|---|
| 家庭裁判所の調停調書謄本または審判書謄本（審判書に確定の表示がない場合は審判確定証明書も） |
| 預金を相続する人の印鑑証明書 |

## 戸籍集めをラクにする方法

- **戸籍の広域交付**：近くの役所で、親の出生から死亡までの戸籍をまとめて請求できます（[戸籍の広域交付](/blog/koseki-kouiki-koufu)）
- **法定相続情報一覧図**：法務局で作ってもらうと、戸籍の束の代わりに使えます。無料で何枚でも出してもらえます（[法定相続情報証明制度](/blog/houtei-souzoku-jouhou)）

口座が複数の銀行にあるときは、法定相続情報一覧図があると、同時に手続きを進めやすくなります。

## 遺産分割の前でも払い戻せる制度

相続人全員の合意がなくても、**一定の額までは遺産分割の前に払い戻せる制度**があります。葬儀費用や当面の生活費が必要なときに使えます。くわしくは[預金の払戻し制度](/blog/yokin-haraimodoshi-seido)をご覧ください。口座の凍結については[親の口座が凍結されたら](/blog/oya-kouza-touketsu)にまとめています。

株式の口座がどこにあるかわからないときは、[亡くなった親の株の調べ方](/blog/kabushiki-souzoku-shirabekata)をご覧ください。

## まとめ

- 銀行に連絡すると、口座の取引は原則止まる。引き落としの変更を忘れずに
- 必要書類は、遺言書・遺産分割協議書・調停調書の有無で変わる
- 戸籍は「出生から死亡までの連続したもの」が必要。広域交付や法定相続情報一覧図が便利
- 急ぎのお金は、遺産分割前の払戻し制度も使える
