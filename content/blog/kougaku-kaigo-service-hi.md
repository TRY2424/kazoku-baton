介護が長くなったり、介護度が重くなったりすると、毎月の介護サービスの自己負担もふくらんでいきます。

そんなときに知っておきたいのが「**高額介護サービス費**」です。1か月の自己負担が、所得に応じた上限額をこえた場合、**こえた分が介護保険から戻ってくる**しくみです。

この記事は、厚生労働省の「介護サービス情報公表システム」に掲載されている資料をもとに書いています（出典は記事の最後に載せています）。

## 1か月の上限額

| 区分 | 対象になる方 | 1か月の上限額 |
|---|---|---|
| 課税所得690万円以上 | 年収約1,160万円以上 | 140,100円（世帯） |
| 課税所得380万〜690万円未満 | 年収約770万〜1,160万円 | 93,000円（世帯） |
| 住民税課税世帯〜課税所得380万円未満 | 年収約770万円未満 | 44,400円（世帯） |
| 住民税非課税世帯 | 下の2つに当てはまらない方 | 24,600円（世帯） |
| 住民税非課税世帯で、年金収入＋その他の所得が82.65万円以下 | | 24,600円（世帯）／15,000円（個人） |
| 生活保護を受けている方など | | 15,000円（個人など） |

※「世帯」は、同じ世帯で介護サービスを使っている方全員の自己負担の合計の上限です。「個人」は、ご本人の上限です。
※ 課税所得での判定は、同じ世帯の65歳以上の方の課税所得で行います。

## 対象にならない費用

高額介護サービス費で計算するのは、介護保険のサービスの自己負担（1〜3割）の部分だけです。次の費用は、合計に入りません。

食費・居住費を軽くする制度は、[負担限度額認定についての記事](/blog/futan-gendogaku-nintei)で解説しています。

## 受け取るには申請が必要

高額介護サービス費は、**市区町村に申請して**受け取ります。対象になった方には、市区町村から申請の案内が届くことが多いので、見落とさないようにしましょう。

## 医療費と合わせて軽くなる制度もある

同じ医療保険の世帯で、**医療費と介護費の両方**の自己負担があった場合は、「**高額医療・高額介護合算制度**」で、1年間（8月〜翌年7月）の合計額が上限をこえた分が戻ってきます。

| 所得の目安 | 75歳以上の世帯の上限（年額） |
|---|---|
| 年収約1,160万円〜 | 212万円 |
| 年収約770万〜約1,160万円 | 141万円 |
| 年収約370万〜約770万円 | 67万円 |
| 〜年収約370万円 | 56万円 |
| 住民税非課税世帯など | 31万円 |
| 住民税非課税で、年金収入82.65万円以下など | 19万円（介護を使う方が複数なら31万円） |

※ 限度額を500円以上こえた場合に支給されます。申請先は、加入している**医療保険**の窓口です。70歳未満・70〜74歳の方は上限額がちがいます。

## まとめ

- 介護サービスの自己負担が1か月の上限をこえると、**こえた分が戻ってくる**
- 上限額は所得によって、15,000円〜140,100円
- 食費・居住費などは対象外。申請が必要
- 医療費も多い世帯は、「高額医療・高額介護合算制度」も確認を
