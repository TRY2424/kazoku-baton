会社員だった人の遺族には遺族厚生年金がありますが、**自営業などで国民年金だけに入っていた人**が亡くなった場合は、遺族年金を受け取れないこともあります。そんなときに確かめたいのが、国民年金の独自の給付である**死亡一時金**と**寡婦年金**です。日本年金機構の公式ページをもとにまとめました（出典は記事の最後に載せています）。

## 死亡一時金

### 受け取れる条件

- 亡くなった人が、死亡日の前日までに国民年金の**第1号被保険者**として保険料を**36か月（3年）以上**納めていた
- 亡くなった人が、老齢基礎年金・障害基礎年金を**受け取っていなかった**
- 遺族基礎年金を受け取れる遺族が**いない**

### 受け取れる遺族の順番

亡くなったときに**生計を同じくしていた**、次の順番の人が受け取れます。

配偶者 → 子 → 父母 → 孫 → 祖父母 → 兄弟姉妹

### 金額

| 保険料を納めた月数 | 金額 |
|---|---|
| 36か月以上180か月未満 | 120,000円 |
| 180か月以上240か月未満 | 145,000円 |
| 240か月以上300か月未満 | 170,000円 |
| 300か月以上360か月未満 | 220,000円 |
| 360か月以上420か月未満 | 270,000円 |
| 420か月以上 | **320,000円** |

付加保険料を36か月以上納めていた場合は、**8,500円**が加算されます。

## 寡婦年金

夫を亡くした妻が受け取れる年金です。

| 条件 | 内容 |
|---|---|
| 夫の期間 | 国民年金の第1号被保険者として保険料を納めた期間と免除期間の合計が**10年以上** |
| 婚姻期間 | 夫と**10年以上**続けて婚姻関係（事実婚を含む）にあった |
| 生計 | 夫に生計を維持されていた |
| 受け取る期間 | 妻が**60歳から65歳になるまで** |
| 金額 | 夫の第1号被保険者期間で計算した老齢基礎年金額の**4分の3** |

夫が老齢基礎年金や障害基礎年金を受け取ったことがある場合や、妻が老齢基礎年金を繰り上げて受け取っている場合は、受け取れません。

## どちらか一方を選ぶ

死亡一時金と寡婦年金の両方を受け取れる場合は、**どちらか一方を選びます**。寡婦年金は60〜65歳の間に毎年受け取る年金なので、受け取れる期間や金額を年金事務所で確かめてから選ぶと安心です。

## 請求のしかた

<div class="steps">

1. 住所地の市区町村の窓口、または年金事務所・街角の年金相談センターに相談する
2. 死亡一時金の場合は「国民年金死亡一時金請求書」を書く
3. 書類をそろえる（亡くなった人の基礎年金番号がわかるもの、戸籍謄本または法定相続情報一覧図の写し、世帯全員の住民票、受取口座の通帳など）
4. 窓口に出す

</div>

日本年金機構によると、配偶者が請求する場合などは、マイナンバーを書くことで戸籍謄本や住民票を省略できる場合があります。

> **死亡一時金は、亡くなった日の翌日から2年をすぎると請求できません**。

## まとめ

- 国民年金の保険料を36か月以上納めた人が年金を受け取らずに亡くなったら、遺族は死亡一時金（12万〜32万円）
- 夫を亡くした妻は、条件を満たせば60〜65歳の寡婦年金
- 両方は受け取れず、どちらかを選ぶ
- 死亡一時金の請求は2年以内。窓口は市区町村か年金事務所
