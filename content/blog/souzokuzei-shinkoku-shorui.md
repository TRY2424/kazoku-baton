相続税の申告では、申告書といっしょに、**相続人や財産を確かめるための書類**を出します。国税庁の「**相続税の申告のためのチェックシート**」をもとに、そろえる書類を整理しました（出典は記事の最後に載せています）。

> ※ 必要な書類は、財産の内容や使う特例によってちがいます。実際の申告は、**税理士や税務署に相談してください**。申告と納付の期限は、亡くなったことを知った日の翌日から10か月以内です（[相続税の申告期限](/blog/souzokuzei-shinkoku-kigen)）。

## 1. 相続人を確かめる書類

| 書類 | ポイント |
|---|---|
| **戸籍の謄本等** | 次のどちらか（コピーでも可） |
| ① 戸籍の謄本 | **相続開始の日から10日を経過した日以後**に作成され、亡くなった人のすべての相続人がわかるもの |
| ② 法定相続情報一覧図の写し | 図の形式のもので、子の続柄が実子か養子かわかるもの |
| 養子の戸籍 | 亡くなった人に養子がいる場合は、その養子の戸籍の謄本または抄本も |

法定相続情報一覧図は、法務局で無料で作ってもらえます（[法定相続情報証明制度](/blog/houtei-souzoku-jouhou)）。戸籍は近くの役所でまとめて取れます（[戸籍の広域交付](/blog/koseki-kouiki-koufu)）。

## 2. 遺産の分け方がわかる書類

| 書類 | ポイント |
|---|---|
| 遺言書の写し | 家庭裁判所の検認を受けた遺言書、または公正証書遺言の写し |
| **遺産分割協議書の写し** | 話し合いで分けた場合（[書き方](/blog/isan-bunkatsu-kyougisho)） |
| **相続人全員の印鑑証明書** | 遺産分割協議書に押したもの。**配偶者の税額軽減や小規模宅地等の特例を使う場合は原本** |
| 申告期限後3年以内の分割見込書 | 申告期限までに遺産を分けられていない場合 |
| 特別代理人選任の審判の証明書 | 相続人に未成年者がいて、特別代理人を選んだ場合 |

配偶者の税額軽減や小規模宅地等の特例は、**遺産が分けられていることが前提**です。分けられていない場合は分割見込書を出し、3年以内に分けることで適用を受けられる場合があります（[配偶者の税額軽減](/blog/haiguusha-zeigaku-keigen)、[小規模宅地等の特例](/blog/shoukibo-takuchi-tokurei)）。

## 3. 財産ごとの資料

| 財産 | 資料の例 |
|---|---|
| 土地・建物 | 固定資産税評価証明書、登記事項証明書、土地の評価明細書など |
| 分譲マンション | 登記事項証明書（2024年からの評価ルール：[マンションの相続税評価](https://www.saikaihatsu-times.com/kaiuri/mansion-souzokuzei-hyouka)） |
| 預貯金 | **相続開始日現在の残高証明書**、預貯金通帳など（既経過利息の計算も） |
| 株式など | 証券、配当金支払通知書、上場株式の評価明細書など |
| 生命保険・退職金 | 保険証券、支払保険料計算書、退職金の支払調書など |
| 借りている土地（借地権） | 賃貸借契約書など |
| 3年以内に取得した土地・建物 | 不動産売買契約書、登記事項証明書 |

国税庁のチェックシートでは、**郵便貯金の計上漏れ**や、**家族名義でも亡くなった人のものと考えられる預金・保険（名義預金など）**がないかの確認も求めています。

## 4. 生前贈与があった場合

亡くなる前の一定期間の贈与や、相続時精算課税の贈与は、相続税の計算に加えます。贈与税の申告書（控え）などを用意します（[生前贈与の加算](/blog/seizen-zouyo-kasan-7nen)、[相続時精算課税](/blog/souzoku-seisan-kazei)）。

## 5. 本人確認書類

申告書を書面で出す場合は、マイナンバーを記載する人の**本人確認書類の写し**の添付が必要です。**e-Taxで申告する場合は、本人確認書類の提示や写しの提出は不要**です。添付書類はイメージデータで出せます。

## 忘れやすい手続き

国税庁のチェックシートでは、亡くなった人の所得税の確定申告（**準確定申告**）が必要な場合は、相続開始日の翌日から**4か月以内**とされています（[準確定申告](/blog/jun-kakutei-shinkoku)）。

## まとめ

- 戸籍の謄本（10日経過後に作成）か法定相続情報一覧図の写し
- 遺産分割協議書の写しと相続人全員の印鑑証明書（特例を使うなら原本）
- 財産ごとの資料（残高証明書、評価証明書など）
- 迷ったら税理士や税務署に相談を
