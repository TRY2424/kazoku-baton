「子どもがいない」「子どもが遠くに住んでいて、すぐには駆けつけられない」。そんな親が入院や施設入所のときに求められるのが、**身元保証人**や**緊急連絡先**です。亡くなったあとの葬儀や役所の手続きを、だれがするかも気になります。

こうしたことを家族の代わりに引き受ける事業者が増えていて、国は**2024年（令和6年）6月**に**「高齢者等終身サポート事業者ガイドライン」**をつくりました。内閣官房（身元保証等高齢者サポート調整チーム）を中心に、内閣府、金融庁、消費者庁、総務省、法務省、厚生労働省、経済産業省、国土交通省がまとめたものです。

この記事は、厚生労働省のサイトに掲載されているガイドラインの本文をもとに書いています（出典は記事の最後に載せています）。

> ※ このガイドラインは、事業者が取り組むことが重要と考えられる事項をまとめたもので、法律による許可制や登録制ではありません。契約するかどうかは、内容をよく確かめて判断してください。

## 「高齢者等終身サポート事業」とは

ガイドラインでは、高齢者などに対して**身元保証、死後事務、日常生活の支援**などを行う事業を「高齢者等終身サポート事業」と呼んでいます（これまでの「身元保証等高齢者サポート事業」という呼び方を改めたもの）。

サービスは、主に次の3つに分けられます。

| 種類 | 主な内容（ガイドラインの例） |
|---|---|
| 身元保証等サービス | 入院・入所のときの連帯保証、入退院・入退所の手続きの代行、亡くなったときや退去時の身柄の引き取り、医療についての意思決定の支援への関わり、緊急連絡先の受託 |
| 死後事務サービス | 死亡の確認と関係者への連絡、死亡届や火葬許可の手続きの代行、葬儀・火葬・納骨・永代供養の手続き、遺品の整理、後期高齢者医療などの資格喪失届、電気・ガス・水道・携帯電話などの解約 |
| 日常生活支援サービス | 通院の送迎・付き添い、買い物の同行、入院・入所のときの引っ越し、公共料金の支払いや生活費の管理、重要書類の保管など |

## 身元保証人がいなくても、入院・入所は断れない

ガイドラインは、厚生労働省の通知を引いて、**医療機関や介護保険施設は、身元保証人などがいないことだけを理由に、入院・入所を断ることは適当でない**としています。

> 病院や施設から身元保証人を求められて困ったときは、まずそのことを病院・施設の相談窓口や、親の住む地域の地域包括支援センターに相談してみましょう。地域包括支援センターについては[はじめての介護、最初の相談先](/blog/kaigo-hajimete)にまとめています。

## どうしてガイドラインができたのか

ガイドラインは、この事業には次のような特徴があり、ふつうの契約より**利用者を守る必要性が高い**としています。

- 将来にわたる身元保証や、亡くなったあとの死後事務を含むため、**契約が長期にわたる**
- サービスより先に、費用の一部を**前払い（預託）**することがあり、契約どおり行われているか確認しにくい
- 判断能力の低下が心配される高齢者が主な利用者で、あとから**契約の有効性をめぐって争いになる**おそれがある

消費生活相談には「契約書が交付されていない」といった相談も寄せられていて、ガイドラインは**契約書をつくって利用者に渡すことが重要**としています。

## 契約前に確かめたい12のこと

ガイドラインは、事業者が利用者に**「重要事項説明書」**として書面で渡し、ていねいに説明することが重要な事項として、次のようなものをあげています。親と一緒に説明を聞くときのチェックリストとして使えます。

| | 確かめたいこと | ガイドラインのポイント |
|---|---|---|
| 1 | サービスの内容と費用 | 入会金や預託金などを**分けて**示し、使うたびに払う費用があればはっきり示す |
| 2 | 支払いの方法 | いつ、いくら、どう払うか。預託金から差し引くなら、引かれた金額と内容を明らかに |
| 3 | サービスの履行状況を確認する方法 | |
| 4 | 入院・入所が必要になったときの対応、医療についての意思決定の支援 | 本人の希望を書面に残しておくことが望ましい |
| 5 | 本人の判断能力が低下したときの対応 | |
| 6 | 損害が出たときの賠償のルール | 事業者の責任をすべて免除する条項などは無効（消費者契約法） |
| 7 | 解約のしかたと、解約したときの返金 | 書面で説明することが特に望ましい |
| 8 | 預託金の管理方法 | |
| 9 | 死後事務として行うサービスの内容 | |
| 10 | 寄附や遺贈についての方針 | |
| 11 | 個人情報の取り扱い | |
| 12 | 相談窓口の連絡先 | |

また、契約の有効性をめぐる争いを防ぐために、**契約のときに医療・介護の関係者や親族などの第三者が立ち会う**ことも考えられる、としています。離れて住む家族も、できれば契約の場に同席しましょう。

### 解約料が高すぎるときは

ガイドラインは、解約料のうち、同じ種類の契約の解除で事業者に生じる**平均的な損害の額をこえる部分は無効**になる（消費者契約法）ことや、利用者から求められたら、事業者は**解約料の算定根拠の概要を説明する努力義務**があることにふれています。

## 前払いのお金（預託金）の管理

亡くなったあとの葬儀費用などのために、お金を前もって預けることがあります。ガイドラインは、事業者が経営破綻した場合などに利用者の被害を小さくするため、預託金について次のようにすることが望ましいとしています。

- 事業者自身の運営資金と**はっきり分けて管理**する
- 利用者に**定期的に管理状況を報告**する
- これらを契約書に書いて、利用者と共有する
- 保全のしかたとしては、**信託銀行・信託会社との信託契約**の利用が望ましい（ほかに、士業などの規制を受ける別法人への管理委託や、分別した預金で管理する方法も考えられる）

> 「預けたお金がどこで、どう管理されるのか」は、契約前に必ず聞いておきたいポイントです。

## ほかの制度とあわせて考える

終身サポート事業だけが選択肢ではありません。判断能力があるうちに準備できる制度もあります。

- 財産の管理や、判断能力が落ちたときの備えは[任意後見](/blog/nini-kouken)や[家族信託](/blog/kazoku-shintaku-toha)
- 遺言は[自筆証書遺言の保管制度](/blog/igonsho-hokan-seido)
- 生前の片づけ全般は[生前整理の進め方](/blog/seizen-seiri-guide)

ガイドラインも、利用者が契約後に判断能力が不十分になった場合は、成年後見（任意後見または法定後見）に移ることを想定しています。

## まとめ

- 身元保証・死後事務・日常生活支援を引き受ける事業を、国は「高齢者等終身サポート事業」と呼び、**2024年6月にガイドライン**をつくった
- 医療機関や介護施設は、**身元保証人がいないことだけを理由に入院・入所を断るのは適当でない**とされている
- 契約前に**重要事項説明書**で、費用、解約と返金、預託金の管理、死後事務の中身などを確かめる
- 預託金は、事業者の資金と**分けて管理**され、定期的に報告があるかを確認
- 契約の場には、できれば家族も同席する
