# サ高住(サービス付き高齢者向け住宅)とは?介護施設との違いを分かりやすく解説

「親の住まいを考えなければいけないけれど、サ高住(さこうじゅう)と介護施設って何が違うの?」

そんな疑問を持って、このページにたどり着いた方も多いのではないでしょうか。介護の世界には聞き慣れない言葉がたくさんあり、いざ調べ始めると余計に混乱してしまうこともあります。このページでは、専門用語をできるだけ使わずに、「サ高住」と「介護施設」の基本的な違いを一つずつ整理していきます。

## サ高住(サービス付き高齢者向け住宅)とは

サ高住とは、正式には「サービス付き高齢者向け住宅」といい、60歳以上の方が安心して暮らせるように作られた**賃貸住宅**の一種です。

ポイントは、あくまで「住宅(お部屋を借りて住む場所)」であるという点です。マンションやアパートに近いイメージを持ってもらうと分かりやすいかもしれません。

サ高住には、最低限次の2つのサービスが付いています。

- **安否確認サービス**:スタッフが定期的に部屋を訪問したり、緊急時に駆けつけたりする見守りの仕組み
- **生活相談サービス**:日常生活の困りごとについて、スタッフに相談できる窓口

これ以外の食事の提供や、入浴・排泄などの介護サービスは、施設によって「あり・なし」が分かれます。必要に応じて、外部の訪問介護サービスなどを別途契約して利用する形が一般的です。

## 介護施設とは

一方で「介護施設」という言葉は、実はいくつかの種類をまとめた総称です。代表的なものに、以下のような施設があります。

- **特別養護老人ホーム(特養)**:常に介護が必要な方向けの公的施設
- **介護老人保健施設(老健)**:在宅復帰を目指すためのリハビリ中心の施設
- **有料老人ホーム**:民間企業が運営する、サービス内容が幅広い施設
- **グループホーム**:認知症の方が少人数で共同生活する住まい

これらの施設は、サ高住とは違い、**施設自体が介護サービスを提供する体制**を持っていることが多いです。つまり「住む場所」であると同時に「介護を受ける場所」でもある、という点が大きな違いです。

## サ高住と介護施設、何が一番違うの?

ここまでの内容を、表で整理してみます。

| 項目 | サ高住 | 介護施設(例:特養・老健など) |
|---|---|---|
| 位置づけ | 賃貸住宅 | 介護サービスを提供する施設 |
| 契約形態 | 賃貸借契約(または利用権方式) | 施設利用契約 |
| 介護サービス | 基本は付いていない(別途契約) | 施設が直接提供することが多い |
| 入居できる方 | 比較的元気な方〜軽い介護が必要な方 | 中重度の介護が必要な方が中心 |
| 自由度 | 外出・外泊などが比較的自由 | 施設のルールに沿った生活 |

簡単に言うと、**「まだそこまで介護は必要ないけれど、一人暮らしは少し不安」という方にはサ高住**が、**「日常的にしっかりした介護が必要」という方には介護施設**が向いている、というイメージです。

## どちらを選べばいいか迷ったときの考え方

実際にご家族の住まいを選ぶ際は、以下のような点を一緒に確認してみてください。

1. **今、どのくらいの介護が必要か**(まったく介護がいらない/見守り程度でよい/日常的な介護が必要)
2. **将来、介護度が上がったときにどうしたいか**(住み替えを前提にするか、長く住み続けたいか)
3. **費用はどのくらい出せるか**(初期費用・月額費用は施設によって大きく異なります)
4. **本人が「住宅」としての自由な暮らしを望んでいるか、それとも手厚いケアを優先したいか**

特に3の費用面や、要介護認定(介護がどのくらい必要かを判定する仕組み)との関係については、別の記事で詳しく解説していますので、あわせて参考にしてください。

## まとめ

- サ高住は「賃貸住宅」、介護施設は「介護サービスを提供する施設」という位置づけの違いがある
- サ高住は比較的自由度が高く、介護施設は手厚いケアが受けられる
- どちらが合うかは、本人の介護の必要度や、将来的な希望によって変わってくる

初めて調べるときは情報量の多さに圧倒されがちですが、「住宅なのか、施設なのか」という軸で考えると、全体像がぐっと分かりやすくなります。次の記事では、介護施設の種類(特養・老健・有料老人ホームなど)を、さらに詳しく比較していきます。
