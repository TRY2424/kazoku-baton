「親を特養に入れたいけれど、大阪市ではどこに申し込めばいいの？」。大阪市の特別養護老人ホーム（特養）は、**市役所や区役所ではなく、入りたい施設に直接申し込みます**。

大阪市の案内と「大阪市指定介護老人福祉施設（特別養護老人ホーム）等 入所選考指針」をもとに、申し込みの流れを整理しました（出典は記事の最後に載せています）。

## 申し込める人

| 要介護度 | 申し込み |
|---|---|
| **要介護3〜5** | 申し込める（自宅での生活がむずかしい人） |
| 要介護1・2 | 次の「特例入所」の要件に当てはまる場合に限り、特例として入所が認められることがある |
| 要支援1・2 | 対象外 |

### 要介護1・2の「特例入所」の要件

大阪市の入所選考指針では、次のいずれかに当てはまり、施設以外での生活が著しく困難と認められる場合に、特例的に入所が認められます。

- 認知症で、日常生活に支障をきたす症状・行動や、意思疎通のむずかしさがよく見られる
- 知的障がい・精神障がいなどを伴い、日常生活に支障をきたす症状・行動や、意思疎通のむずかしさがよく見られる
- 家族などによる深刻な虐待が疑われるなど、心身の安全・安心の確保がむずかしい
- 単身世帯や、同居の家族が高齢・病弱、育児や仕事などで家族の支援が期待できず、地域の介護サービスや生活支援も十分でない

この要件に当てはまると申し立てた場合、**施設は申し込みを受け付けないことはできない**とされています。

## 申し込みの方法

<div class="box"><div class="box-head">入りたい施設に、本人または家族が直接申し込む</div><div class="box-text">ケアマネジャーが申し込みを手伝う</div></div>

### 必要な書類

| 書類 | 内容 |
|---|---|
| 入所申込書兼台帳（様式1） | 本人・家族が記入 |
| 入所選考調査票（様式2） | 原則として**ケアマネジャー**などが意見を書く |
| 介護保険被保険者証の写し | |
| 要介護認定調査票の基本調査の写し | |
| 直近3か月分のサービス利用票の写しと、サービス利用票別表の写し | |

要介護1・2で特例入所を希望する場合は、特例入所の要件に当てはまることと、施設以外での生活が著しく困難な理由を、申込書と調査票に書き添えます。

**まずは担当のケアマネジャーに「特養に申し込みたい」と相談**するのが近道です。ケアマネジャーは申し込みに必要な援助をすることになっています。

## 入所の順番の決まり方

入所は**申し込み順（先着順）ではありません**。各施設に置かれた「入所選考委員会」（毎月1回程度開催）が、次の基準で評価し、必要性の高い人から順番を決めます。

| 基本的な評価基準 |
|---|
| ① 要介護度 |
| ② 世帯の状況 |
| ③ 在宅サービスの利用率 |
| ④ 地域性による評価 |

これに加えて、施設ごとに、緊急性、ベッドの特性、家族の介護の負担、離れて住む親族の近くの施設に入る場合の配慮などの「個別的な評価事項」も考えます。

災害や事故などで緊急に入所が必要な場合は、委員会を開かずに施設長が入所を決めることもできます。

## 施設の探し方

大阪市は、市内の特養の一覧（Excel・PDF）を公表しています。定員29人以下の地域密着型の施設は、原則として**大阪市民のみ**が利用できます。空き状況は一覧には載っていないので、施設に直接問い合わせましょう。

## 費用は

特養の費用は、介護サービスの自己負担のほか、居住費や食費がかかります。目安は[老人ホームの費用](/blog/roujin-home-hiyou)、所得が低い場合に居住費・食費が軽くなる制度は[負担限度額認定](/blog/futan-gendogaku-nintei)をご覧ください。待機の実態は[特養の入居条件と待機期間](/blog/tokuyo-nyukyo-taiki)にまとめています。
