「遺言は公正証書で作ったほうが安心と聞いたけれど、費用はいくら？」。公正証書遺言の手数料は、**公証人手数料令**という政令で決まっていて、どの公証役場でも同じ計算です。

日本公証人連合会の手数料表（**2025年10月1日施行の改正後**）をもとに整理しました（出典は記事の最後に載せています）。

> ※ ここで紹介するのは公証役場に払う手数料です。遺言の内容の相談や書類集めを弁護士・司法書士・行政書士などに頼む場合は、その報酬が別にかかります。

## 公正証書遺言の手数料のしくみ

1. **財産を受け取る人ごとに**、受け取る財産の額（目的の価額）で手数料を出す
2. それを**合計**する
3. 財産の総額が**1億円以下**なら、**1万3,000円を加算**（遺言加算）
4. 正本・謄本の発行の手数料などをたす

## 手数料表（2025年10月1日から）

| 目的の価額（受け取る人ごと） | 手数料 |
|---|---|
| 50万円以下 | 3,000円 |
| 50万円超〜100万円以下 | 5,000円 |
| 100万円超〜200万円以下 | 7,000円 |
| 200万円超〜500万円以下 | 1万3,000円 |
| 500万円超〜1,000万円以下 | 2万円 |
| 1,000万円超〜3,000万円以下 | 2万6,000円 |
| 3,000万円超〜5,000万円以下 | 3万3,000円 |
| 5,000万円超〜1億円以下 | 4万9,000円 |
| 1億円超〜3億円以下 | 4万9,000円に、5,000万円までごとに1万5,000円を加算 |

（日本公証人連合会「公証人手数料」より。3億円をこえる場合は出典をご覧ください）

2025年10月の改正で、50万円以下の区分が新しくでき、少ない額の手数料が下がりました。

## 計算例

### 例1：妻に3,000万円、長男に1,000万円を相続させる

| 内容 | 手数料 |
|---|---|
| 妻（3,000万円） | 2万6,000円 |
| 長男（1,000万円） | 2万円 |
| 遺言加算（総額4,000万円で1億円以下） | 1万3,000円 |
| **合計** | **5万9,000円**＋正本・謄本の手数料 |

### 例2：長女にすべて（2,000万円）を相続させる

| 内容 | 手数料 |
|---|---|
| 長女（2,000万円） | 2万6,000円 |
| 遺言加算 | 1万3,000円 |
| **合計** | **3万9,000円**＋正本・謄本の手数料 |

## そのほかにかかる費用

| 項目 | 費用 |
|---|---|
| 正本・謄本（紙） | 用紙1枚につき300円 |
| 祭祀主宰者（お墓などを受け継ぐ人）の指定 | 1万3,000円 |
| 病院や自宅など、公証役場の外で作る場合（病床執務） | 手数料に2分の1を加算 |
| 公証人の出張 | 日当2万円（4時間以内は1万円）と交通費の実費 |
| 遺言の撤回 | 原則1万3,000円 |

親が入院していたり、体が弱って公証役場に行けなかったりする場合でも、公証人に来てもらって作ることができます。その分の加算があります。

## 証人が2人必要

公正証書遺言を作るときは、**証人2人**の立ち会いが必要です（民法）。未成年者や、推定相続人・受遺者とその配偶者・直系血族などは証人になれません（民法974条）。

証人を頼める人がいないときは、作成を依頼する公証役場に相談してください。

## 自筆の遺言とどちらがいい？

| | 公正証書遺言 | 自筆証書遺言 |
|---|---|---|
| 費用 | 公証人の手数料がかかる | 紙とペンで作れる。法務局に預けるなら3,900円 |
| 形式の不備 | 公証人が作るので、形式で無効になりにくい | 書き方を間違えると無効になることがある |
| 家庭裁判所の検認 | いらない | いる（法務局に預けた場合はいらない） |

自分で書く場合は[遺言書の書き方](/blog/igonsho-kakikata)、法務局に預ける制度は[遺言書保管制度](/blog/igonsho-hokan-seido)、検認は[遺言書の検認](/blog/igonsho-kennin)をご覧ください。

## まとめ

- 公正証書遺言の手数料は、受け取る人ごとに計算して合計し、1億円以下なら1万3,000円を加算
- 2025年10月の改正で、50万円以下の区分ができた
- 病院や自宅で作るときは加算と出張費がかかる
- 証人2人が必要
