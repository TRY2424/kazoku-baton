「毎年110万円までなら、親からもらっても大丈夫」とよく聞きます。何が大丈夫で、何に気をつければいいのでしょうか。

この記事は、国税庁タックスアンサー「No.4402 贈与税がかかる場合」「No.4408 贈与税の計算と税率（暦年課税）」（**令和8年4月1日現在法令等**）をもとに書いています（出典は記事の最後に載せています）。

> ※ 実際に税金がかかるかは個別の事情によります。**税務署か税理士に確認してください。**

## 基本のルール

| 項目 | 内容 |
|---|---|
| 数える期間 | **1月1日〜12月31日**の1年間 |
| 数える単位 | もらった人の、その年の合計 |
| 基礎控除 | **110万円** |
| 110万円以下なら | 贈与税はかからず、**申告も不要** |
| 110万円をこえたら | 翌年**2月1日〜3月15日**に申告と納税 |
| 申告先 | 所轄の税務署 |

「もらった人の合計」がポイントです。父と母の両方から同じ年に100万円ずつもらうと、もらった人の合計は200万円なので、110万円をこえます。

## 税額の計算

**（1年でもらった合計 − 110万円）× 税率 − 控除額** で計算します。税率は2種類あります。

### 特例税率（特例贈与財産）

贈与の年の1月1日に**18歳以上**の人が、**父母や祖父母など直系の尊属**からもらった場合です（配偶者の親からは対象外）。

| 基礎控除後の金額 | 税率 | 控除額 |
|---|---|---|
| 200万円以下 | 10% | — |
| 400万円以下 | 15% | 10万円 |
| 600万円以下 | 20% | 30万円 |
| 1,000万円以下 | 30% | 90万円 |
| 1,500万円以下 | 40% | 190万円 |
| 3,000万円以下 | 45% | 265万円 |
| 4,500万円以下 | 50% | 415万円 |
| 4,500万円超 | 55% | 640万円 |

### 一般税率（一般贈与財産）

兄弟姉妹や夫婦の間の贈与、親から未成年の子への贈与などです。

| 基礎控除後の金額 | 税率 | 控除額 |
|---|---|---|
| 200万円以下 | 10% | — |
| 300万円以下 | 15% | 10万円 |
| 400万円以下 | 20% | 25万円 |
| 600万円以下 | 30% | 65万円 |
| 1,000万円以下 | 40% | 125万円 |
| 1,500万円以下 | 45% | 175万円 |
| 3,000万円以下 | 50% | 250万円 |
| 3,000万円超 | 55% | 400万円 |

### 500万円をもらったときの例（国税庁）

| | 計算 | 税額 |
|---|---|---|
| 特例税率 | （500万円−110万円）×15%−10万円 | **48万5,000円** |
| 一般税率 | （500万円−110万円）×20%−25万円 | **53万円** |

## 気をつけたいこと

**亡くなる前の贈与は、相続税に足されることがあります。** くわしくは[生前贈与の加算](/blog/seizen-zouyo-kasan-7nen)をご覧ください。

**別のしくみとの選択もあります。** 親からの贈与には[相続時精算課税](/blog/souzoku-seisan-kazei)という制度もあります。

**親が認知症のときは要注意。** 親の判断能力が下がると、財産の管理や手続きがむずかしくなることがあります。[親の認知症と資産凍結](/blog/oya-ninchisho-shisan-touketsu)もご覧ください。

## まとめ

- 贈与税の基礎控除は、**もらった人の合計で1年110万円**。以下なら申告も不要
- こえたら、翌年2月1日〜3月15日に申告と納税
- 18歳以上が親などからもらうと特例税率、それ以外は一般税率
- 亡くなる前の贈与は相続税に足されることがある。迷ったら税務署か税理士へ
