親が施設に入った、親が亡くなって実家を相続した。そんなとき、多くのご家族が悩むのが「**実家をどうするか**」です。

思い出の詰まった家だからこそ、決めるのは簡単ではありません。でも、空き家のまま置いておくと、お金も手間もかかり続けます。

この記事は、実家の売却について**いちばん最初に読んでほしい入門ガイド**です。

## まずは「売る・貸す・残す」を考える

<div class="fig">
<div class="fig-title">実家の3つの選択肢</div>
<div class="boxes three">
<div class="box accent"><div class="box-head">売る</div><div class="box-text">管理の手間がなくなり、まとまったお金になります。相続人で分けやすいのも利点です。</div></div>
<div class="box"><div class="box-head">貸す</div><div class="box-text">家賃収入が入り、家も残せます。ただし、リフォーム費用や、入居者の管理が必要です。</div></div>
<div class="box"><div class="box-head">残す・住む</div><div class="box-text">家族が住む、または将来のために残します。空き家のままだと、管理や税金の負担が続きます。</div></div>
</div>

## 実家を売るまでの流れ

<div class="fig-title">実家売却の6ステップ（期間の目安：3〜6か月）</div>
<div class="steps">
<div class="step"><div class="step-no">1</div><div><div class="step-head">相続登記（名義変更）</div><div class="step-text">亡くなった親の名義のままでは売れません。まずは相続人の名義に変更します。</div></div></div>
<div class="step"><div class="step-no">2</div><div><div class="step-head">2〜3社に査定を依頼</div><div class="step-text">不動産会社によって査定額や対応が大きく違うため、必ず複数社で比べます。</div></div></div>
<div class="step"><div class="step-no">3</div><div><div class="step-head">不動産会社と媒介契約</div><div class="step-text">売却をお願いする会社を決めて、契約を結びます。</div></div></div>

相続登記については、[実家を売る前に、相続登記が済んでいるか確認してください](/blog/souzoku-toki-baikyaku)でくわしく解説しています。

## 「仲介」と「買取」のちがい

| | 仲介 | 買取 |
|---|---|---|
| 買う人 | 一般の個人など | 不動産会社 |
| 売れる価格 | 相場に近い価格で売りやすい | 相場の7〜8割程度になることが多い |
| 売れるまでの期間 | 3〜6か月程度 | 早ければ数週間 |
| 仲介手数料 | かかる | かからないことが多い |
| 向いているケース | 時間をかけても高く売りたい | 早く現金化したい、古くて売れにくい |

## 売却にかかる主な費用

| 費用 | 目安 |
|---|---|
| 仲介手数料 | 売却価格×3%＋6万円＋消費税（売却価格が400万円をこえる場合の上限） |
| 印紙税 | 売買契約書に貼る印紙。売却価格によって数千円〜数万円 |
| 登記費用 | 相続登記、住宅ローンが残っていれば抵当権の抹消など |
| 測量費 | 土地の境界がはっきりしない場合。数十万円かかることも |
| 家財の片付け費用 | 家の広さやモノの量によって、数万〜数十万円 |
| 解体費用 | 更地にして売る場合。木造なら1坪あたり数万円が目安 |
| 税金 | 売って利益が出た場合にかかることがある（くわしくは税務署・税理士へ） |

## 相続した実家には「3,000万円の特別控除」がある

親がひとりで住んでいた実家を相続して売る場合、条件を満たすと、**売却の利益から最大3,000万円（相続人が3人以上なら2,000万円）を差し引ける特例**があります。1981年5月31日以前に建てられた家であること、売却代金が1億円以下であることなど、条件がとても細かく決められています。親が老人ホームなどに入っていた場合も、条件を満たせば対象になります。

くわしい条件は、国税庁の情報をもとにまとめた[空き家の3,000万円控除についての記事](/blog/akiya-3000man-koujo)をご覧ください（出典：国税庁「[No.3306](https://www.nta.go.jp/taxes/shiraberu/taxanswer/joto/3306.htm)」）。実際に使えるかどうかは、**税務署や税理士に必ず確認**しましょう。

## 親が認知症になると、実家が売れないことも

親が存命中に実家を売る場合、親の判断能力が低下していると、売買契約を結べなくなることがあります。将来売る可能性があるなら、**親が元気なうちの備え**が大切です（くわしくは[資産凍結についての記事](/blog/oya-ninchisho-shisan-touketsu)、[家族信託とは？](/blog/kazoku-shintaku-toha)）。

## まとめ

- 実家は「売る・貸す・残す」から選ぶ。空き家のままは負担が続く
- 売却は、相続登記 → 査定 → 契約 → 売り出し → 引き渡しの流れで、3〜6か月が目安
- 高く売りたいなら「仲介」、早く売りたいなら「買取」
- 相続した空き家には、最大3,000万円の特別控除が使える場合がある（税務署・税理士に確認を）

> ※ この記事は2026年9月時点の情報をもとにしています。税金や特例の条件は、法改正で変わることがあります。実際の手続きは、専門家にご確認ください。
