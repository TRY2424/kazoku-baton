神戸市に住む親の特別養護老人ホーム（特養）を探しはじめたら、まず知っておきたいのが**申し込み方**と**入る順番の決まり方**です。

神戸市は、神戸市老人福祉施設連盟と共同で「**特別養護老人ホーム入所指針**」を作り、市内の特養はこれにそって入所者を決めています。指針とQ&Aをもとにまとめました（出典は記事の最後に載せています）。

## 申し込めるのは誰？

| 要介護度 | 申し込み |
|---|---|
| 要介護3〜5 | 申し込める（常に介護が必要で、家での介護がむずかしい人） |
| 要介護1・2 | 原則は不可。やむを得ない事情がある場合だけ「**特例入所**」の対象 |
| 自立・要支援1・2 | 申し込めない |

神戸市のQ&Aによると、要介護認定の申請中（新規・変更・更新）の人は、原則として結果が出てから申し込みます。

### 要介護1・2の特例入所の条件

神戸市のQ&Aでは、次の①〜④のどれかに当てはまり、指針の評価で**65点以上**の場合に特例入所の対象としています。

1. 認知症で、日常生活自立度がⅡb以上。日常生活に支障が出る症状や、意思疎通のむずかしさがよく見られる
2. 知的障害・精神障害などで、同じような状態がよく見られる
3. 家族などによる深刻な虐待が疑われ、心身の安全が守れない
4. 単身世帯、同居の家族が高齢や病弱などで家族の支援が期待できず、地域の介護サービスや生活支援も足りない

特例の対象になっても、**優先して入れるわけではなく**、ほかの人と同じように選考されます。

## 申し込みのながれ

<div class="steps">

1. 担当のケアマネジャー（えがおの窓口＝居宅介護支援事業所、または施設のケアマネジャー）に相談する
2. 「入所申込書」と「入所調査票」をそろえる。神戸市の入所指針（処理要領）によると、認定調査票・被保険者証・直近3か月分のサービス利用表などの写しを添える
3. ケアマネジャーを通して、希望する施設に出す
4. 各施設の「入所検討委員会」が、指針の点数などをもとに入所する人を決める
5. 年1回届く「継続の確認」の調査票に答えて返送する

</div>

申込書と調査票の様式（Excel・PDF）と記入見本は、神戸市の「神戸市特別養護老人ホーム入所指針」のページにあります。

### ケアマネジャーがいないときは？

神戸市のQ&Aによると、本人が申し込むのが原則ですが、むずかしいときは家族が本人の意思を確かめて代わりに申し込めます。市外に住む人で、ケアマネジャーの協力が得られない場合は、本人や家族が直接施設に申し込むこともできます。

## 入る順番はどう決まる？

神戸市の指針では、**申込順ではなく**、次の項目を点数で評価します。

| 評価する項目 |
|---|
| 要介護度 |
| 認知症の有無 |
| 知的障害・精神障害などの有無 |
| 在宅サービスの利用状況 |
| 老人保健施設や病院などへの入所・入院の期間 |
| 家での介護のむずかしさ（介護する人がいるか、介護する人の入院・高齢・障害、複数の要介護者がいる、仕事・子育てなど） |

点数に表れにくい事情（老々介護や介護疲れなど）は、申込書の介護者の意見欄や、調査票のケアマネジャー記入欄に書いてもらい、施設の委員会で総合的に考える、とQ&Aにあります。

## よくある質問

**Q. いくつの施設に申し込める？**

A. 神戸市のQ&Aによると、**複数の施設に申し込めます**。ただし、必要性が高い人は比較的短い期間で入れるようになっていることや、施設が地域性（住んでいる場所など）も考えることから、広い範囲で多くの施設に申し込む必要はない、としています。

**Q. 一度申し込めば、ずっと有効？**

A. 年1回、申し込みを続けるかの確認調査があります。神戸市のQ&Aによると、確認の調査票を返送せず、2年以上続ける意思が確認できないと、申し込みが**取り消し**になります。要介護度が変わったときや辞退するときも、施設に伝えます。

**Q. いつ入れるか教えてもらえる？**

A. 神戸市のQ&Aでは、退所する人の数や時期で変わり、あとから必要性の高い人が申し込むこともあるため、入所時期の見込みは答えられないとしています。個人の点数は、問い合わせれば答えられると考えている、としています。

## まとめ

- 神戸市の特養は原則要介護3以上。要介護1・2は条件つきの特例入所
- 申し込みは原則ケアマネジャーを通して、入所申込書と入所調査票を出す
- 入る順番は申込順ではなく点数で評価。複数の施設に申し込める
- 年1回の継続確認を返送しないと、取り消しになることがある
